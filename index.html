vrOS

macOS desktop → iPhone VR headset, over USB

Low-latency H.264 streaming from your Mac to a Cardboard-compatible mobile VR headset. All-hardware pipeline: ScreenCaptureKit → VideoToolbox → Metal.

How it works

1

Capture

ScreenCaptureKit grabs the primary display at 1920×1080 @ 30 fps.

2

Encode

VideoToolbox hardware-encodes frames to H.264 Annex B format with SPS/PPS config packets.

3

Stream

Frames are packetized in a custom binary protocol and sent over TCP via USB tethering — iproxy 2345 2345.

4

Decode

iOS receives the packets, converts Annex B to AVCC NALUs, and feeds them to VTDecompressionSession.

5

Render

Metal shaders apply barrel distortion and chromatic aberration correction per eye, rendered side-by-side via instanced draw calls.

Features

⚡

All-hardware pipeline

ScreenCaptureKit → VideoToolbox H.264 → Metal GPU render — no software fallbacks, minimal CPU load.

🔌

USB transport

No Wi-Fi needed. Communication runs over USB tethering via TCP (iproxy port forwarding).

🥽

VR lens correction

Barrel distortion shader compensates for VR headset lenses, with configurable K1/K2 parameters.

🔬

Chromatic aberration

Per-channel distortion offsets (red/blue) to cancel lens-induced color fringing at screen edges.

👁️

Stereo SBS rendering

Side-by-side stereo via Metal instanced draw calls. Each eye renders independently with its own lens distortion.

📦

Custom wire protocol

30-byte binary header (magic, type, seq, timestamp, checksum) + variable payload for config, video, and control packets.

🦺

Swift 6 concurrency

Actors, AsyncStreams, and strict Sendable throughout. The encoder is a Swift actor; the network layer uses async streams.

📊

Latency HUD

On-screen overlay shows connection state, resolution, framerate, frame/packet counts, decoder status, and estimated latency.

Wire Protocol

Custom binary protocol over TCP, port 2345. Each packet starts with a 30-byte header.

Packet types

TypeValuePayload

NALU format: macOS sends Annex B (start-code prefixed). iOS converts to AVCC (4-byte length-prefixed) before feeding to VideoToolbox.

Setup

1

Generate projects

chmod +x setup_xcode_projects.sh && ./setup_xcode_projects.sh

2

Configure signing

Open each .xcodeproj in Xcode and set your development team in Signing & Capabilities.

3

Build & run

Install both apps from Xcode — macOS sender and iOS receiver.

4

Forward USB & connect

iproxy 2345 2345 — then launch the iOS app (listener), then the macOS app (start streaming).

Requirements

  • macOS 13.0+ (Ventura) — sender
  • iOS 16.0+ — receiver
  • Xcode 15.0+ with Swift 6 language mode
  • USB cable (for tethering + iproxy forwarding)
  • A Cardboard-compatible VR headset for the iPhone
