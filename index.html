vrOS
macOS → iPhone VR Desktop Streaming

Your desktop. In a VR headset. Over USB.

vrOS captures your macOS display, encodes it to H.264 in real-time, and streams it over USB to an iPhone for low-latency viewing inside a Google Cardboard or similar mobile VR headset.

How it works

  1. Capture — ScreenCaptureKit grabs the primary display at 1920×1080 @ 30 fps.
  2. Encode — VideoToolbox hardware-encodes frames to H.264 Annex B.
  3. Stream — Frames are packetized and sent over TCP via USB tethering (iproxy 2345 2345).
  4. Decode — iOS receives and decodes H.264 frames via VideoToolbox.
  5. Render — Metal shaders apply barrel distortion and chromatic aberration correction for VR lenses, rendered side-by-side for stereo viewing.

Key features

  • All-hardware pipeline — ScreenCaptureKit → VideoToolbox encode/decode → Metal GPU render
  • Low latency over USB tethering — no Wi-Fi dependency
  • VR lens correction — barrel distortion with configurable K1/K2 parameters
  • Chromatic aberration correction — per-channel distortion for red/blue fringing
  • Stereo side-by-side rendering via Metal instanced draw calls
  • Custom binary wire protocol — 30-byte header + variable payload with SPS/PPS config packets
  • Swift 6 concurrency — actors, AsyncStreams, and strict Sendable throughout

Built with

ScreenCaptureKit VideoToolbox Metal Network.framework SwiftUI Swift 6 CoreVideo CoreMedia

Requirements

  • macOS 13.0+ (Ventura) — sender
  • iOS 16.0+ — receiver
  • Xcode 15.0+ with Swift 6 language mode
  • USB cable (for tethering + iproxy forwarding)
  • A Cardboard-compatible VR headset for the iPhone
